A 4 KB Python chess engine: negamax alpha-beta with iterative deepening on a fixed node budget, transposition table, quiescence search, null-move pruning and late-move reductions, over a 0x88 board with material + piece-square evaluation.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
